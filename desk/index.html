Install

  1. Mac, Windows, or Linux. Chrome, Edge, Brave, or Chromium. Not Safari. Not Firefox.
  2. Download the zip. Unzip it. Keep the folder that contains manifest.json (Windows Extract All sometimes nests an extra folder).
  3. chrome://extensions or edge://extensions → Developer mode → Load unpacked.
  4. Extension Details → turn on Allow User Scripts if Chrome shows it. That lets hot-swap through a strict CSP.
  5. Pin P. Hover is P. Green means the agent armed.
  6. Keep this desk open at 127.0.0.1 while you edit. No reinstall. No re-drag.

Why a runtime

Bookmarklets need a re-drag. Store extensions wait for review. A normal Load-unpacked folder still is the agent, so every edit is an extension Reload. PageArm installs the shell once and keeps the agent on this desk. Hash matches: it just calls arm(). Hash changed: it evals the new source into the page, all frames, MAIN world.

For software and AI agents

Put PageArm in a project when the work has to happen in a tab the human already logged into, and the agent will change more often than the hosts. The shell stays frozen. You keep shipping /agent.js. Use it for internal admin, daily forms, a companion next to software you already ship. Skip it for Store listings, stealth, headless farms, or a drawer of fifty scripts. Coding agents: read AGENTS.md and the README section with the same name.

How hot-swap works

The installed shell fetches /agent.js, hashes it, and evals it into MAIN world if the hash is new. Same hash: it just calls agent.arm(). Desk down: packed inject.js still runs. Changing hosts still needs a new zip. Chrome, not the desk, owns host_permissions.
