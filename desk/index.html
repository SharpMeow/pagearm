    Why a runtime

    Bookmarklets need a re-drag. Store extensions wait for review. A normal unpacked extension still is the agent, so every edit is a reload. PageArm installs the shell once and keeps the agent on this desk. Hash matches: it just calls arm(). Hash changed: it puts the new source into the page, all frames, MAIN world.

    For software and AI agents

    Put PageArm in a project when the work has to happen in a tab the human already logged into, and the agent will change more often than the hosts. The shell stays frozen. You keep shipping /agent.js. Use it for internal admin, daily forms, a companion next to software you already ship. The drawer here holds as many saved scripts as you like, but only one is ever the agent. Skip PageArm for store listings, stealth, headless farms, or fifty scripts live on fifty sites at once. Coding agents: read AGENTS.md and the README section with the same name.

    How hot-swap works

    The installed shell fetches /agent.js, hashes it, and puts it into MAIN world if the hash is new. Same hash: it just calls agent.arm(). Desk down: packed inject.js still runs. Changing hosts still needs a new zip. The browser, not the desk, owns host_permissions.
