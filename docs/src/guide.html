  3. Chromium: Load unpacked. Firefox: about:debugging, Load Temporary Add-on. Safari: convert it in Xcode first.

  5. Edit the agent. Hit Save. Open a matching tab. No reinstall. No re-drag.
  6. Keep more in the drawer. The stack says which ones run, in order, as one agent.
